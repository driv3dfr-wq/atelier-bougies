# Atelier bougies

Logiciel d'atelier bougies (page unique) et page de choix des invités.

- `index.html` : le logiciel (les données restent dans le navigateur).
- `choix.html` : la page que les invités ouvrent depuis le lien envoyé par l'organisateur.

Aucune donnée personnelle n'est stockée dans ce dépôt.
